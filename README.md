# 🔐 Rakshak – Password Manager

Rakshak is a secure and user-friendly password manager that helps you store, manage, and protect your credentials with ease.

---

## 🛡️ Features

- 🔒 Secure storage of usernames & passwords
- 🧠 Easy-to-use UI for managing credentials
- ✨ Real-time password masking & toggling
- 🔍 Search functionality to find saved credentials
- 🗑️ Option to delete or update stored passwords
- 🖥️ Responsive design across all devices
- 🛠️ Built using the MERN Stack (MongoDB, Express, React, Node.js)

---

## 📂 .env
- MONGO_URI=your_mongodb_connection_string
- WT_SECRET=your_jwt_secret

## 💡 Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Auth: JWT (JSON Web Tokens)

## Install Dependicies 

Backend:
  - cd server
  - npm install
  - npm run dev

Frontend:
- cd client
- npm install
- npm run dev
